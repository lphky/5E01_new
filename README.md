# 極速狂飆

純前端 Canvas 賽車遊戲，直接開啟 `index.html`，或使用 GitHub Pages：
https://lphky.github.io/5E01_new/

方向鍵或 WASD 控制方向、煞車和氮氣；P 暫停。手機使用畫面按鈕。
遊戲進度與排行榜儲存在瀏覽器本機，介面樣式使用 Tailwind CDN。

GitHub Pages 從 `main` 分支根目錄發布。
